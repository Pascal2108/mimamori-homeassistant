# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately instead:

1. Open the [Security tab](https://github.com/Pascal2108/mimamori-homeassistant/security) of this repository.
2. Click **Report a vulnerability** and fill in the form.

Only the maintainer can see the report. Describe what an attacker can do and what they need for it, the steps to reproduce it, and the versions you tested. Leave out API tokens, host names and serial numbers of a real setup.

A problem in mimamori itself (the server or its API) goes to the [mimamori repository](https://github.com/Pascal2108/mimamori/security) instead.

## What happens next

The integration is maintained in spare time, so these are aims, not promises: an answer within **7 days**, a fixed version as soon as possible, and a GitHub security advisory once it is released. Please give the fix time to be released before you publish details.

## Supported versions

Only the newest release gets security fixes.
